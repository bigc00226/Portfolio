# バナーの動画について

トップページのバナーは、このフォルダにある次のファイルを探します。

| ファイル名 | 状態 | 役割 |
| --- | --- | --- |
| `banner.mp4` | **設置済み** | バナーの動画（1280×720・15秒・約4.7MB）。 |
| `banner-poster.jpg` | **設置済み** | 読み込み中に表示する一枚絵。動画の冒頭から書き出しています。 |
| `banner.webm` | 未設置 | 任意です。置けば、対応しているブラウザで優先されます。 |

差し替えられる場合は、同じ名前で上書きしていただくだけで反映されます。ファイル名は
`src/data/site.ts` で変更できます。

どのファイルが実際に置かれているかはサーバー側で確認しているため、存在しない
ファイルをブラウザが取りにいくことはありません（`banner.webm` がなくても、
404 は出ません）。`npm run dev` では次の再読み込みから反映されます。本番環境では、
ファイルを差し替えたあとに `npm run build` をもう一度実行してください。

## 表示のしかた

- ページ全体に合わせて、動画は白黒で表示しています。
  `src/components/VideoBanner.module.css` の `.video` にある
  `filter: grayscale(1) contrast(0.78) brightness(1.2)` と、`.scrim` の最後に
  重ねた白のレイヤー（不透明度 0.42）で、明るい紙面になじむ階調にそろえています。
  この動画は場面によって明るさの差が大きいため、コントラストを抑えて白をかぶせ、
  どの場面でも明るさが揃うように調整しています。
- 見出しの載る左下には白を厚く重ねているため、動画の明暗にかかわらず文字が読めます。
- ブラウザが自動再生を許可する条件に合わせ、音声を消した状態で繰り返し再生します。
  再生と音声は、画面右下のボタンから切り替えられます。
- OS で「視差効果を減らす」を設定されている方には、動かない一枚絵を表示します。

## 差し替えの目安

1920×1080 以下、H.264、容量は6MB以下を目安になさってください。これより重いと、
最初の表示が目に見えて遅くなります。色は白黒に変換されるため、色味よりも
明暗の差と動きの大きさのほうが仕上がりに効いてきます。
