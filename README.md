# Love Apple｜システム＆AIエンジニアのポートフォリオ

Next.js 16（App Router・React 19・TypeScript）で作成した、一枚もののポートフォリオ
サイトです。トップページは、ご指定のとおり次の三つだけで構成しています。

1. **バナー** — 画面いっぱいの動画に、見出しを重ねたもの。
2. **開発実績** — 分野ごとの件数と、15業種・54件の一覧。分野と業種で絞り込めます。
3. **お客様の声** — 平均評価と、9件のご感想。

それ以外の要素は、意図して置いていません。

もう一枚、`/home` に **物語のページ** があります。両親の出会いから現在までを、
スクロールに合わせて動く白黒の絵で読み進めるランディングページです。
詳しくは「[物語ページ（/home）](#物語ページhome)」をご覧ください。

さらに `/design` に、**写真の帯が 3D で流れるページ**があります。スクロールに
合わせて、写真の帯が円軌道を描きながら、大きな見出しの前後を回っていきます
（Three.js を使用）。そのあとに、ペンを持った手が書いていく文章、大きく流れていく
「L❤veApple」、暗いハートが広がって現れる紹介文、15 の業種が横に流れるギャラリー、
切り替わっていく白いカード（ABOUT）、奥行きのある写真の壁（仕事の進め方）、
開発実績の紹介、ご相談の入口が続きます。
詳しくは「[デザインページ（/design）](#デザインページdesign)」をご覧ください。

## 動かし方

```bash
npm install     # node_modules が同梱されている場合は不要です
npm run dev     # http://localhost:3000
npm run build   # 本番用のビルド
npm start       # ビルドしたものを配信
npm run typecheck
```

## はじめに書き換えたい三か所

### 1. お名前と見出し — `src/data/site.ts`

ロゴの文字（`name`。いまは **Love Apple**）、ブラウザのタブに出る文言、バナーの
見出し、動画のファイル名は、すべてこのファイルにまとめています。ロゴの文字は、
全ページの左上とフッター、各ページの小見出しに出ます。公開前に `url` を
ご自身のドメインへ変更してください。SNS でのリンク表示に使われます。

ロゴ画像は `src/images/logo.png` です。差し替えられる場合は同じ名前で上書きして
いただければ、ヘッダー・フッターの両方に反映されます。ブラウザのタブに出る
アイコンは `src/app/icon.png` で、ロゴから 256×256 に書き出したものです。
ロゴを差し替えられた際は、こちらも合わせて差し替えてください。

### 2. バナーの動画 — `public/media/`

いただいた `bg_movie.mp4` を `public/media/banner.mp4` として設置済みです
（1280×720・15秒）。読み込み中に表示する `banner-poster.jpg` も、動画の冒頭から
書き出して置いてあります。差し替えられる場合は、同じ名前で上書きしてください。
詳しくは `public/media/README.md` をご覧ください。

ファイルが見つからない場合は、用意した静止画面に切り替わります。未完成には
見えませんので、差し替えの途中でも安心してお使いいただけます。

### 3. 開発実績 — `src/data/projects.ts`

**件数は手で書いた数字ではなく、一覧から自動で数えています。**
各案件に、関わった分野を付けてあり、上部の三つの数字はその集計です。

| 分野 | 件数 |
| --- | --- |
| システム開発 | 49件 |
| アプリ開発 | 23件 |
| AI開発 | 35件 |

多くの案件が複数の分野にまたがるため、それぞれの分野に計上しています。三つの
合計が54件を超えるのはそのためで、ページ上にもその旨を記載しています。案件を
追加・削除したり、分野を付け替えたりすると、ヘッダーや絞り込みバーの数字も
含めて、ページ全体が自動的に追従します。

### 4. 業種のイラスト — `src/images/industries/`

いただいた16点のイラストを、業種の識別子で保存しています（`agriculture.png`、
`manufacturing.png` など。「すべての業種」は `all.png`）。差し替えられる場合は、
同じ名前で上書きしていただくだけで反映されます。

イラストは二か所で使っています。

- **業種から探す** — 開発実績の上に並ぶタイル。業種の絞り込みを兼ねています。
- **業種の見出し** — 一覧をたどっていく途中の、各業種の目印として。

**既定では白黒で表示し、指を置いたときと選択中のときだけ本来の色に戻します。**
ページ全体を白と黒でまとめているためですが、常に色のままにされたい場合は、
`src/components/ProjectRecords.module.css` の `.tileImage img` と
`.groupImage img` にある `filter` の行を削っていただくだけで切り替わります。

表示は `next/image` に任せているため、WebP や AVIF への変換、画面幅に応じた
書き出し、遅延読み込み、読み込み中のぼかしは自動で行われます。

### 5. お客様の声 — `src/data/reviews.ts`

`src/data/reviews.ts` にはお客様の声を置いています。**初回のビルドから完成した
状態でご覧いただけるよう、代表的な内容として書き起こしたサンプルです。公開前に、
実際にいただいたお言葉へ差し替えてください。** 平均評価は、このファイルの内容
から計算しています。企業名ではなく役職と業種でご紹介する形にしてあります。

## 物語ページ（/home）

`http://localhost:3000/home` で開きます。導入、12章の物語、結び（ご相談の案内）の
三つで組み立てています。トップページ（`/`）の内容はそのままで、今のところ
`/` から `/home` へのリンクも置いていません。結びのボタンからは、`/` の開発実績と
お客様の声へ移動できます。

### 文言を書き換える — `src/data/story.ts`

ページに出る文字は、すべてこのファイルにあります。

- `hero` … 導入の見出しと挨拶。
- `chapters` … 各章の見出し（`title`）と、スクロールに合わせて切り替わる文
  （`beats`）。`at` は、その文を出し始める位置（章の進み具合 0〜1）です。
- `labels` … 絵の中の文字。ビルの看板（`company`）、名札、TODO の予定、
  「株式会社」の看板、クラウドワークスとランサーズの画面の題など。
- `outro` … 結びの見出しと、ボタンの文言・行き先。

**最初の章の看板は、いただいた文面の「Hitach」を `HITACHI` として描いています。**
表記が違う場合は、`labels.company` と、第1章の文を直してください。

### 章の長さを変える

各章の `weight` が、その章にかけるスクロール量です。大きくするほど絵がゆっくり
動きます。全体の速さは `src/components/story/timeline.ts` の三つの数字
（絵が動く長さ・止めて見せる長さ・次の章へ送る長さ）で決まります。

### 絵を直す — `src/components/story/scenes/`

章ごとに一つのファイルです（`Office.tsx`、`Project.tsx`、… `Loved.tsx`）。
絵は 1200 × 800 の座標に描いた SVG で、画像ファイルは使っていません。

- 置いてある場所が、その章の **仕上がった絵** です。
- `<M k="…" a={…} b={…}>` で包むと、章の進み具合 `a`〜`b` のあいだに、
  そこへ向かって動きます（`in` は現れる、`walk` は歩いてくる、`pop` は弾む、など）。
- 人物は `kit.tsx` の `Figure` です。`who` に `mother`・`father`・`me` を渡すと、
  母（ベレー帽とワンピース）、父（めがねとネクタイ）、私（頭のひと房と胸の
  ハート）を描き分けます。腕や脚の角度、表情、持ちものも指定できます。
- 色は、ほかのページと同じく白と黒だけです。仲間やお客様は、淡い灰色の人物
  （`ghost`）として描き分けています。

### 動きのしくみ

舞台を画面に固定し、スクロール位置を各章の進み具合に置き換えています
（`StoryFilm.tsx`）。絵の動きは止めたままの CSS アニメーションで、いま動いて
いる要素だけを、進み具合に合った時刻へ送ります。アニメーション用のライブラリは
使っていません。

- **JavaScript を無効にしている場合と、「視差効果を減らす」設定の場合**は、
  舞台を固定せず、章が上から順に並んだ読みものとして表示します。絵は、
  各章の仕上がった状態です。
- 画面下の目盛りは章へのリンクで、キーボードでも移動できます。右上の
  「物語をとばす」で、結びまで進めます。
- 映していない章の文も読み上げの対象に残しているため、スクリーンリーダーでは
  物語を最初から最後までたどれます。

## デザインページ（/design）

`http://localhost:3000/design` で開きます。上から順に、次の十で組み立てています。
トップページ（`/`）と物語ページ（`/home`）からのリンクは、まだ置いていません。

1. 最初の画面（写真の帯と、大きな見出し）
2. 書かれていく文章（「愛されるエンジニア」）
3. 流れる大きな文字（「L❤veApple」）
4. ハートの幕と、紹介文（「LOVE APPLE — TECHNOLOGY × DESIGN × DEVELOPMENT」）
5. 業種のギャラリー（15 の業種）
6. ABOUT の見出しと、切り替わっていく四枚の白いカード
7. 仕事の進め方（写真の壁と、手書きの一語）
8. 開発実績の紹介（PROJECT RECORDS）
9. ご相談の入口（CONTACT）と、もう一度流れる「L❤veApple」
10. いちばん下の案内（ロゴ、ページの案内、流れる写真の帯）

このページには専用の案内（10）があるので、全ページ共通のフッターは、ここでは
表示しません。

最初の画面は、スクロールすると次の順に動きます。写真の帯は、縦に立てた大きな
輪の上を一周します。最初に大きく迫ってくる動きではなく、輪に沿って回りこんで
くる動きです。

1. 開いた直後、帯が輪の奥側（左下）へ回りこんできて止まる。
2. 帯が輪の左端で折り返し、手前を大きく、右上がりに横切っていく。
   同時に、輪そのものが画面の下から上へ昇り、見出しの前を通る。
3. 淡い色で置かれた二行目「♡愛される♡」が、赤い手書きの線で書かれていく。
   左のハート、「愛」「さ」「れ」「る」（書き順どおりに一画ずつ）、右のハートの順。
4. 帯は右端でもう一度折り返し、見出しの後ろを小さく流れて、輪の奥で消える。
5. 見出しが上の行から順に抜け、右の赤いハートだけが残る。
6. 次の見出し「愛されるエンジニア」が、下からせり上がる。

最初の画面を固定しているあいだは、左上のロゴ（ヘッダー）も画面に残ります。

### 書かれていく文章と、流れる大きな文字

見出し「愛されるエンジニア」のあとに、本文が続きます。スクロールすると、
**画面の下から現れた行が、左から順に書かれていきます。** 行が画面の下端に入った
ときに書きはじめ、画面の中央まで上がったときに書き終えます（はじめは速く、
終わりへ向けてゆるやかに進みます）。

- **小さな字**は、淡い色で置かれていて、左から黒へ変わっていきます。
- **大きな色の字**は、書かれるまで見えません。ペンを持った手が、書いている端を
  追いかけながら書いていきます。書き終えると、行の終わりに小さな絵が現れ、
  手は消えます。
- 最後の大きな行「そんな「愛されるエンジニア」を、」には、書くのに合わせて
  黄色いマーカーの下線が引かれます。
- 画面が狭くて行が折り返すときは、読む順に、次の行へ続けて書かれます。

そのあとに、大きな「L❤veApple」が、右から左へ流れ続けます。
スクロールすると、そのぶんだけ余分に流れます。

### ハートの幕、紹介文、業種のギャラリー

流れる大きな文字が画面の上へ抜けていくころ、**画面の中央に暗いハートが現れ、
スクロールに合わせて広がって、画面ぜんたいを覆います。** 同時に地の色も暗くなり、
ここから先は、暗い画面になります。

- **紹介文** … 小見出しは、左の字から順に、下から上がってきます。本文は、一行ずつ
  下から上がってきます。
- **業種のギャラリー** … 画面を固定し、スクロールに合わせて、湾曲した画像の帯を
  右から左へ流します。帯は、手前にふくらんだ円筒に貼りついたように見え、中央ほど
  大きく、左右の端ほど小さく、細くなります。速く流すと、画像の中ほどが先へ
  たわみます。
- 画像が中央へ来るたびに、**大きな業種名が、一文字ずつ現れて切り替わります。**
  画像の下の欧文、下端の番号（01〜15）も一緒に変わり、目盛りは帯と一緒に流れます。
- 画像にポインターを載せると、その画像が白黒になり、業種名がその業種のものに
  変わって、色が付きます。

### ABOUT のカード、仕事の進め方、開発実績、ご相談の入口

業種のギャラリーのあとは、次のように動きます。どの動きも、スクロールの位置から
決めているので、**上へ戻ると、同じ道すじを逆にたどります。**

- **ABOUT の見出し** … ギャラリーの最後の画像が左へ抜けていくのと入れ替わりに、
  見出しが、一文字ずつ縦に回りながら、右から入ってきます。画面の中央に着くと、
  ギャラリーの固定が外れます。そのあと、見出しはゆっくり上へ動いて薄れます。
- **白いカード** … 見出しの上へ、少し小さいところから広がりながら重なり、画面に
  固定されます。スクロールすると、大きな見出しの二行が上へ畳まれ、次の見出しが
  下から伸びてきます（四枚）。番号、説明文、ボタンの色、丸い札も一緒に替わり、
  目の付いたハートが、見出しの上を跳ねて移ります。右端の点を押すと、そのカードへ
  移れます。
- **仕事の進め方** … カードが上へ抜けていくと、その下から、小見出しと文章が、
  半分の速さで現れます。続いて、左右に二列ずつの写真の壁が現れ、手前の列は
  スクロールのおよそ 2.2 倍、奥の列は 1.2 倍の速さで、上へ流れていきます。
  見出しの最後の一語「Love.」は、スクロールに合わせて、手書きで書かれます。
- **開発実績** … 暗い地のまま、大きな見出しが下から現れ、一行目は右から、
  二行目は左から寄ってきます。区画が画面を占めたところで、地の色が明るく
  切り替わり（上へ戻ると、また暗くなります）、三件の実績が下から浮かび上がります。
- **ご相談の入口** … 黒い地に、背景の大きな語、見出し、行き先のボタンを重ねます。
  その下を、もう一度「L❤veApple」が流れ、いちばん下の案内へ続きます。案内の中の
  写真の帯は、手前にふくらんだ形に切り抜いてあり、ゆっくり左へ流れます。

また、このページでは、**ホイールでのスクロールを、なめらかにしています**
（`SmoothWheel.tsx`）。ホイールを回したぶんへ、ページがすっと追いつくので、
スクロールに合わせた動きが、段々にならずに流れます。キーボード、スクロールバー、
タッチでのスクロールは、ブラウザのままです。

### 写真を差し替える — `src/images/design/`

**いま並んでいるのは、本番の写真が用意できるまでの仮の画像です**（左下に
`SAMPLE 01` などの札が入っています）。`01.jpg`〜`08.jpg` を同じ名前で上書きすれば、
そのまま差し替わります。帯の枠は 16:9 です。比率の違う写真は、ゆがめずに、
枠いっぱいになるよう切り抜いて表示します。枚数を変える場合は、
`src/data/design.ts` の `frames` を増減してください。帯には 10 枚ぶん並べるので、
足りない分は先頭からくり返します。

**業種のギャラリーの画像も、仮の絵です**（`src/images/design/industries/` の
`agriculture.jpg` など 15 枚。業種ごとに描いたサンプルで、同じく `SAMPLE` の札が
入っています）。同じ名前で上書きすれば差し替わります。枠は 13:8 で、比率の違う
写真は、枠いっぱいになるよう切り抜いて表示します。開発実績の三件と、いちばん下の
写真の帯にも、この画像を使っています。

**写真の壁と、白いカードの見出しの絵も、仮の絵です。**

- `src/images/design/scenes/` … 写真の壁に並べる、仕事の場面の絵 12 枚
  （`hearing.jpg`・`design.jpg`・`code.jpg` など。枠は 5:6 の縦長）。
- `src/images/design/strips/` … 白いカードの見出しに並べる、横長の絵 8 枚
  （`values-wide.jpg`・`story-tile.jpg` など。枠に合わせて切り抜きます）。

どちらも、同じ名前で上書きすれば差し替わります。どの位置にどの絵を出すかは、
`src/data/design.ts` の `work.near`・`work.far`（写真の壁）と、`profile.cards` の
`rows`（カードの見出し）で決めています。

### 文言を書き換える — `src/data/design.ts`

見出しの三行、左右の端の縦書き、「愛されるエンジニア」の本文とボタン、最後に流れる
文字は、このファイルにあります。

見出しは「システム＆AI ／ 愛される ／ エンジニア」の三行で、二行目（`middle`）の
両側にハートが付きます。

**二行目を書く手書きの線は、文字ではなく、字ごとに用意した線の絵です**
（`handwriting.ts` の `GLYPHS`）。いま用意しているのは「愛・さ・れ・る」の四つで、
見出しの書体の各画の中心を、書き順どおりになぞっています。二行目の文言を変える
場合は、新しい字の線を `GLYPHS` に足してください。線のない字は、手書きにならず、
黒い字のまま表示されます。位置を文字数から決めているので、二行目は全角の文字で
書いてください。

**本文は `concept.stanzas` です。** 空行で区切られるひとかたまりを一つの配列にし、
その中に行を並べます。行の書き方で、見え方が決まります。

```ts
stanzas: [
  [
    "私は、", // 文字列だけ → 小さな字（淡い色から黒へ）
    // write を持つ行 → 手で書かれる大きな字。tone は色、icon は終わりの絵
    { write: "ただシステムを作るエンジニアではありません。", tone: "blue", icon: "megaphone" },
  ],
  // before / after は、大きな字の前後に、同じ行のまま添える小さな字
  [{ before: "それが、", write: "私の考えるエンジニアの仕事", after: "です。", tone: "green", icon: "code" }],
  // marker: true で、黄色いマーカーの下線が付きます
  [{ write: "そんな「愛されるエンジニア」を、", tone: "ink", icon: "heart", marker: true }],
],
```

- `tone` … `blue`・`orange`・`green`・`red`・`ink`（黒）
- `icon` … `megaphone`・`heart`・`gear`・`palette`・`bulb`・`sprout`・`question`・
  `code`・`bubble`（絵は `writingArt.tsx` にあります）

流れる大きな文字は `flow` です。`heavy`（太い字）の中の `❤` のところに、ハートの
絵が入ります。

紹介文は `about` です。`label` が小見出し、`paragraphs` が本文で、段落ごとに行を
並べます。

業種のギャラリーは `industries.items` です。並びは、トップページの開発実績
（`src/data/projects.ts`）と同じ 15 業種です。

```ts
// lines は大きく出す業種名。長い名前は、行ごとに分けて書きます（つなげると業種名になります）
// caption は画像の下に小さく添える欧文
{ id: "logistics", lines: ["物流・運輸・", "モビリティ"], caption: "LOGISTICS, TRANSPORT & MOBILITY", image: imgLogistics },
```

ABOUT の見出しとカードは `profile` です。`cards` の一枚ぶんは、次のように書きます。

```ts
{
  id: "history",
  tone: "yellow", // 差し色：green・yellow・orange・blue
  heading: "PROFILE & HISTORY", // 読み上げと、動かない表示で使う見出し
  // 大きな見出しは二行。字（text）と絵（image）を、左から並べます。
  // tinted: true の字は、差し色になります。size: "fill" の絵は、行の残りの幅いっぱいに広がります。
  rows: [
    [{ text: "PROFILE" }, { text: "&", tinted: true }, { image: stripStoryTile, size: "fill" }],
    [{ image: stripStoryWide, size: "fill" }, { text: "HISTORY", tinted: true }],

  text: ["一行目", "二行目", "三行目"], // 説明文
  href: "/home", // ボタンの行き先
  badges: ["palette", "sprout"], // 丸い札の絵（icon と同じ名前）
},
```

仕事の進め方は `work`、開発実績は `records`、ご相談の入口は `contact`、いちばん下の
案内は `footer` です。

- `work.title` の `script`（手書きの一語）は、文字ではなく、線の絵です
  （`WorkWall.tsx` の `SCRIPT`。いまは「Love.」だけ）。語を変える場合は、線も
  描き直してください。
- `records.items` は、`record("08", 画像)` のように、開発実績（`projects.ts`）の番号で
  選びます。題名・業種・分野の札は、そこから自動で入ります。
- **`contact.links` と、`footer` の CONTACT の行き先は、いまは CrowdWorks と
  Lancers のトップページです。公開前に、ご自身のプロフィールページの URL へ
  書き換えてください。**

### 動きを調整する

- **帯の通り道** … `src/components/design/ribbon.ts` の `KEYS`。進み具合ごとに、
  帯の先頭が輪のどこにいるか、輪をどこに・どんな向きで置くかを並べた表です。
  輪と写真の大きさは、同じファイルの `RADIUS`（輪の半径）・`FRAME_HEIGHT`
  （写真の高さ）・`COUNT`（枚数）で決まります。
- **画面を固定しておく長さ** … `DesignHero.tsx` の `PIN`。大きくするほど、
  ゆっくり動きます。
- **ハートと手書きの線の色** … `Design.module.css` の `--accent`（赤）。
  書かれる前の淡い色は、字が `--ghost`、ハートが `--ghost-heart` です。
- **手書きを書く時期** … `DesignHero.tsx` の `WRITE`（書きはじめと書き終わり）と
  `WIPE`（消しはじめと消し終わり）。画面を固定しているあいだの進み具合で
  指定します。
- **本文が書かれる範囲** … `Writing.tsx` の `FROM` と `TO`。行の上端が、画面の
  どこからどこまで動くあいだに書くかを、画面の高さに対する割合で指定します
  （いまは下端の `1` から中央の `0.5` まで）。ペン先の位置は `NIB` です。
- **本文の字の大きさと色** … `Writing.module.css` の先頭にある `--small`・`--big`
  （字の大きさ）、`--blue` などの色、`--marker`（マーカー）、`--faint`
  （書かれる前の淡い色）。
- **大きな文字が流れる速さ** … `LoveFlow.module.css` の `.track` にある
  `animation` の秒数（一つぶん流れるのにかかる時間）。スクロールで余分に流れる
  量は、`LoveFlow.tsx` の `DRIFT` です。
- **ハートが広がる長さ** … `HeartVeil.tsx` の `SPAN`（広がりきるまでにスクロール
  する長さ。画面の高さに対する割合）。はじめの傾きは `TILT`、暗い地の色は
  `Design.module.css` の `--night` です。
- **ギャラリーの流れる速さ** … `IndustryReel.tsx` の `RATE`（帯が、スクロールの
  何倍の速さで流れるか）。大きくするほど、画面を固定しておく長さが短くなります。
  流れるときのたわみは `BOW`、ポインターを載せたときの色は `TONES` です。
- **ギャラリーの形** … `reelShape.ts`。円筒の半径（`RADIUS`）と視点の距離
  （`FOCUS`）、画像の幅・高さ・間隔（`WIDTH`・`HEIGHT`・`PITCH`）、業種名を
  切り替える位置（`SWITCH`）をまとめています。最後の画像が中央を過ぎたあとの
  流れ方は、`EXIT`（どこまで流すか）と `HURRY`（速さの割り増し）です。
- **ABOUT の見出しとカード** … `AboutCards.tsx` の先頭。`REACH`（見出しが入って
  くる距離）、`ROLL`（字が回る時期）、`DRIFT`・`FADE`（上へ動く速さと薄れ方）、
  `SHRINK`（カードのはじめの大きさ）、`TURN`（切り替えの範囲）。カード一枚ぶんの
  スクロールの長さは、画面の高さひとつ分です。
- **写真の壁** … `WorkWall.tsx` の `NEAR`・`FAR`（列の位置、傾き、流れる速さ）と
  `WRITE`（手書きを書く範囲）。写真の大きさと間隔は `WorkWall.module.css` の
  `.near`・`.far`、手書きとボタンの色は `--love` です。
- **開発実績の見出し** … `Records.tsx` の `FROM`（二行のはじめのずれ）、`SPAN`
  （寄ってくるまでの長さ）、`LIGHT_AT`（地の色を切り替える位置）。
- **ホイールのなめらかさ** … `SmoothWheel.tsx` の `GLIDE`（ページが追いつくまでの
  時間。ミリ秒）。大きくするほど、ゆったり流れます。`0` にすると、ブラウザの
  ふつうのスクロールに戻ります。

### しくみ

見出しは HTML の文字のままにして、帯だけを Three.js で描いています。帯を
「文字より奥」と「文字より手前」の二枚のキャンバスに描き分け、文字をそのあいだに
挟むことで、輪の手前半分は文字の前を、奥の半分は文字の後ろを通るように
見せています。

- Three.js（`three`）は、このページを動かせるときにだけ読みこみます
  （gzip でおよそ 134KB）。トップページと物語ページでは読みこみません。
- **JavaScript を無効にしている場合と、「視差効果を減らす」設定の場合**は、
  画面を固定せず、見出しと画像の並びだけの動かない画面を表示します。
- **WebGL が使えない環境**でも、同じ画像の並びに切り替わり、見出しとハートの
  動きはそのまま残ります。

本文は、ふつうの HTML の文字です。字を「字の形で切り抜いた塗り」で描き、その
塗りの境目をスクロールに合わせて動かすことで、書かれていくように見せています。
ペンを持った手と小さな絵は、SVG で描いた絵です。

- サーバーが返す HTML では、本文はすべて書き終わった姿で並んでいます。
  **JavaScript を無効にしている場合と、「視差効果を減らす」設定の場合**は、
  そのまま読める形で表示し、大きな文字も流さずに止めておきます。

ハートの幕は、画面に貼りつけた一枚の SVG です。流れる文字より手前、紹介文と
ギャラリーより奥に挟んであり、ハートの大きさと地の暗さを、スクロールに合わせて
書き換えています。広がりきったあとは、そのまま後半の暗い背景になります。

業種のギャラリーは、画像の帯だけを Three.js で描き、業種名・番号・目盛りは HTML の
文字のまま重ねています。円筒への貼りつけと遠近は、頂点シェーダーの中で計算して
います。

- サーバーが返す HTML では、ギャラリーは、画像と業種名を並べた一覧です。
  **JavaScript を無効にしている場合、「視差効果を減らす」設定の場合、WebGL が
  使えない環境**では、ハートの幕は出さずに（WebGL が使えないだけなら幕は出ます）、
  暗い背景の上に、紹介文とこの一覧をそのまま表示します。
- 動かしているあいだも、一覧は読み上げ用に残してあります。
- 画像と Three.js は、ギャラリーが画面に近づいてから読みこみます。

ギャラリーより下の区画は、どれも HTML と CSS の変形だけで動かしています
（Three.js は使っていません）。

- **ABOUT の見出し**は、画面に貼りつけた層に置き、位置をスクロールから決めて
  います。字は、同じ字を縦に二つ重ねたものを、窓の中で上へ送って回しています。
- **白いカード**は、画面に固定した一枚の中に四枚ぶんを重ね、見出しの行を縦に
  伸び縮みさせて切り替えています。
- **写真の壁**は、CSS の 3D 変形です。手前の列は、外側の端がこちらへ迫り出す
  ように傾けた壁で、遠近は `perspective` で付けています。
- **手書きの一語**は、一本の線の絵（SVG）を、書いたぶんだけ見せています。

これらの区画も、サーバーが返す HTML では、そのまま読める形で並んでいます。
**JavaScript を無効にしている場合と、「視差効果を減らす」設定の場合**は、見出しを
その場に置き、四枚のカードを縦に並べ、写真の壁を動かさない背景にし、開発実績を
はじめから明るい地で表示します。ホイールのなめらかなスクロールも、行いません。

## 構成

```
src/
  app/                レイアウト、ページ、全体のスタイル、ファビコン
    home/             物語ページ（/home）
    design/           デザインページ（/design）
  components/         セクションごとの部品と、それぞれの CSS モジュール
    story/            物語ページの部品。scenes/ に章ごとの絵があります
    design/           デザインページの部品。ribbon.ts が写真の帯、Writing.tsx が
                      書かれていく文章、LoveFlow.tsx が流れる大きな文字、
                      HeartVeil.tsx がハートの幕、IndustryReel.tsx と reel.ts が
                      業種のギャラリー、AboutCards.tsx が ABOUT の見出しとカード、
                      WorkWall.tsx が写真の壁、Records.tsx が開発実績、Contact.tsx と
                      DesignFooter.tsx がページの終わりを描きます。scrollClock.ts は、
                      スクロールを追いかける共通の時計です
  data/               サイト設定、開発実績、お客様の声、物語とデザインページの文言
  fonts/              同梱している woff2 ファイル
  images/industries/  業種のイラスト16点
  images/design/      デザインページの帯に並べる写真（いまは仮の画像）。
                      industries/ に業種の画像、scenes/ に写真の壁の絵、
                      strips/ にカードの見出しの絵（どれも仮の絵）
  lib/                サーバー側の補助処理
public/media/         バナーの動画とポスター画像
```

- **スタイル**は CSS モジュールと、`src/app/globals.css` にまとめた少数の
  カスタムプロパティだけで組んでいます。CSS フレームワークは使っていないので、
  追加で覚えていただくことも、更新に追われることもありません。
- **角の丸み**は `globals.css` の `--radius-xs`（6px）から `--radius-xl`（24px）、
  および `--radius-pill` までの変数にまとめています。ボタンやタグは
  `--radius-pill`、カード類は `--radius` と `--radius-lg` を使っています。
  変数の値を変えれば、ページ全体の丸みが一度に変わります。
- **カードは、細い枠線と余白で区切っています。** 以前は 1px の隙間で罫線を
  作っていましたが、角を丸めると成立しないため、各カードに枠線を持たせる
  組み方へ変更しました。指を置くと枠線が少し濃くなり、わずかに浮き上がります。
- **書体**は、欧文に Archivo と Inter、和文に Noto Sans JP を使っています。
  欧文の二つはリポジトリに同梱しているため、ビルド時に外部の配信元へ接続する
  必要がありません。和文は `next/font/google` 経由で、Google の unicode-range
  分割を保ったまま配信します。ブラウザはそのページで使う文字の分だけを読み込みます。
  デザインページだけは、見出しの一部に明朝の斜体（Instrument Serif）を使っており、
  これも `next/font/google` 経由で、そのページでだけ読みこみます。
- **色は白と黒だけ**です。奥行きは、粒子・織り目・段組みの罫・周辺の沈みという
  四つの層（`src/components/Texture.tsx`）で作っています。バナーの動画も業種の
  イラストも白黒で表示し、色は操作したときにだけ現れます。デザインページだけは
  例外で、写真をそのままの色で見せ、ハートと手書きの線に赤を使っています。
- **クライアント側で動く部品は、トップページでは三つだけ**です。バナー、
  絞り込みのできる実績一覧、そして表示と数え上げの小さな補助部品。物語ページ
  では、スクロールを絵の進み具合に置き換える `StoryFilm` ひとつです。デザイン
  ページは、スクロールに合わせて動かす区画ごとに一つずつ（`DesignHero`・
  `Writing`・`LoveFlow`・`HeartVeil`・`IndustryReel`・`AboutCards`・`WorkWall`・
  `Records` など）あります。ほかはすべて、絵も含めてサーバー側で描画しています。
- **追加しているライブラリは Three.js だけ**です。デザインページの写真の帯に
  使っています。

## 配慮している点

- JavaScript を無効にしていても、ページは正しく表示されます。表示アニメーション
  と件数は、完成した状態でサーバーから返し、読み込まれたあと、画面が描かれる前
  にだけ初期状態へ戻しています。
- 「視差効果を減らす」設定を尊重しています。バナーの動画は止まり、件数は最初から
  最終的な数字で表示され、動きは省かれます。
- 絞り込みは `aria-pressed` を持つ本物のボタンで、件数は読み上げにも伝わります。
  実績へ飛ぶスキップリンクも用意しています。
- 和文の組版として、`palt`（詰め）、`word-break: auto-phrase`（文節での折り返し）、
  `line-break: strict`（禁則処理）を指定しています。
- 1440px・768px・390px・320px で確認し、横方向のはみ出しとコンソールのエラーが
  ないことを確かめています。物語ページは、これに加えて 1920px と、横向きの
  スマートフォン（740 × 360）でも確認しています。デザインページは 1912px・
  1440px・390px で確認しています。

## 公開について

Node が動くサーバー、または Vercel にそのまま載せられます。ページは静的に生成
されるため、公開後にバナーの動画を追加された場合は、もう一度 `npm run build` を
実行してください。
